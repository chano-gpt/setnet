**スマホ 1 台で、種類の違うコーディングエージェントをまとめて追う。**

setnet は、[Herdr](https://herdr.dev) の上で動くエージェントの群れをスマホから監督するための web UI だ。Tailscale の中でしか開かない —— クラウドもアカウントもない。

他のツールと決定的に分かれる点はひとつ。**setnet はエージェントを種類ごとに区別して扱う。** ターミナル画面をそのままミラーリングして投げ渡すのではなく、ハーネスごとに何ができて、何をさせてはいけないかを知っている —— Claude Code、Codex、pi、OpenCode、そして **AGY と OMO(Senpi)** まで。

## 何が違うのか

もっとも近い選択肢は [Collie](https://github.com/AltanS/collie) だ —— setnet はここから分岐した。Collie はどのエージェントも単一の汎用ターミナルミラーとして扱う。setnet はその上に**ハーネスを理解する層**を重ねている。

| | setnet | Collie |
|---|---|---|
| **AGY・OMO(Senpi) 対応** | 専用のコマンドカタログ + トランスクリプトアダプター | なし |
| **エージェントの起動** | アプリから 6 種類を起動し、ハーネスごとの安全な引数を固定(Claude は `--permission-mode manual`、Codex は `--ask-for-approval on-request --sandbox workspace-write`) | すでに存在するペインに接続するだけ |
| **プロンプトの送信経路** | ダッシュボードからはすべてのエージェントを Herdr `agent.prompt` で直接送信 —— ターミナル入力を迂回する | PTY にキーを打ち込む経路のみ |
| **プランの進捗** | Senpi の todo-state を解析し、現在のフェーズとタスクごとの状態(待機/進行中/完了/中断)を会話に表示 | なし |
| **ダッシュボードから直接指示** | ペインを開かずにプロンプトを送信、IME セーフな下書き、リアルタイムの作業経過時間 | ペインを開く必要がある |
| **モバイルナビゲーション** | 専用タブバー(群れ / スペース、要対応数のバッジ付き) | 単一のダッシュボード |
| **バンドルコマンドの正直さ** | カタログごとに `partial`(不完全)・`insert-only`(自動実行しない)を明示し、出典も記載 | 完全な一覧であるかのように提示 |
| **非対応ハーネス** | 2 段階の確認を通さない限り入力を拒否 | そのまま一度に送信 |
| **返信ボディの検証** | 形式が不正なリクエストは拒否 | 欠けたフィールドを黙ってデフォルト値で埋める |

**セキュリティモデルとデプロイ形態は Collie のまま手を入れていない** —— ループバックバインド、`tailscale serve` という単一の入口、same-origin ゲート。すでに検証されたものを作り直す理由はない。

## 対応ハーネス

| ハーネス | コマンドカタログ | 会話履歴 | 画面文法の認識 | アプリから起動 |
|---|---|---|---|---|
| **AGY**(Antigravity) | ✅ AGY 1.1.12 時点 | — | — | ✅ |
| **OMO**(Senpi) | ✅ Senpi 2026.8.12-4 時点 | ✅ + プラン進捗 | ✅ | ✅ |
| Claude Code | ✅ | ✅ | ✅ 完全な文法 | ✅(`--permission-mode manual`) |
| Codex | ✅ | ✅ | — | ✅(承認要求 + workspace-write サンドボックス) |
| pi | ✅ | ✅ | — | ✅ |
| OpenCode | ✅ | ✅ | — | ✅ |
| omp | ✅ | — | ✅ 基本 | — |

「画面文法の認識」とは、ターミナル画面から選択肢・ウィザード・入力欄の状態を読み取るアダプターのことだ。完全な文法(プロンプト選択、ウィザード、プレビュー、複数選択、メニュー)を持つのは Claude Code だけで、OMO は omp のアダプターを共用する。アダプターがないハーネスは汎用ミラーに落ち、会話履歴のアダプターがないハーネス(AGY、omp)では履歴機能そのものが出ない。

コマンドカタログは**意図的に不完全だ。** ワークスペースのスキル・プラグイン・MCP プロンプトが実行時にコマンドを追加するため、setnet は自分が実際に知っているものだけを `partial` と明示したうえで公開し、その出典も示す。そして**タップしても実行されない** —— 入力欄に挿入するだけで、送信するのは人間だ。実行時のコマンド集合は揺れるし、非対応のコマンドは副作用を起こしうる。

## 主な機能

**ハーネスを理解した操作**
- ハーネスごとのスラッシュコマンドパレット —— 入力欄で `/` を打つとインラインメニューが出て、タップで挿入
- アダプターのないハーネスへの入力はブロックされ、2 段階の確認を経ないと通らない
- ペインで返信するときは、画面を読んで入力欄が準備できているかを確認し、送った文字が実際に入ったことを検証してから初めて送信キーを押す —— ダイアログがキーボードを握っている最中の Enter が、そのダイアログに答えてしまう事故を防ぐ
- OMO のように検証されたターミナル入力文法を持たないハーネスは、Herdr の管理されたライフサイクル(`agent.prompt`)経由で送る —— PTY には一切触れない

**会話履歴**
- エージェント自身のセッションログから読むので、ターミナルがスクロールバックで戻れない範囲まで届く
- OMO のプランは独立したブロックとして描画され、現在のフェーズと完了数まで表示される
- ライブ会話ビューはポーリングに上限を設け、ページが隠れれば停止し、進行中のリクエストは中断する

**モバイルファースト**
- ホーム画面にインストールできる PWA
- 群れ / スペースのタブバー、対応が必要なエージェント数のバッジ付き
- ダッシュボードは「最後に変わった順」ではなく、**「あなたを待っている順」**に並ぶ
- 特殊キーパッド(`Esc`、`Ctrl+C`、矢印)、カメラロールからの画像送信、出力内の検索
- エージェントが詰まった瞬間に Web Push で通知

**自分のものとして持つ**
- 自分のマシンで動く。ループバックバインド、クラウドなし、アカウントなし
- 玄関は自分で選ぶ —— デフォルトは `tailscale serve`、あるいは自前のリバースプロキシ

## インストール

ホスト側 —— エージェントが動いているマシンで実行する。スマホではない。

```bash
herdr plugin install chano-gpt/setnet
herdr plugin action invoke start --plugin herdr.collie
```

ローカルクローンで開発する場合:

```bash
git clone https://github.com/chano-gpt/setnet.git && cd setnet
herdr plugin link "$(pwd)"
herdr plugin action invoke start --plugin herdr.collie
```

> プラグイン id は今のところ `herdr.collie` のままだ。リブランディングが既存のインストールを壊さないと確認できるまで変えない。

必要なもの: [Bun](https://bun.sh)、[Herdr](https://herdr.dev) 0.7.0 以上、[Tailscale](https://tailscale.com)、git。初回起動時のバナー・アップデート・トラブルシューティングはすべて[運用マニュアル](OPERATIONS.md)にある。

## セキュリティ — 必ず先に読むこと

**setnet は設計上、あなたのマシンへのリモートシェルアクセスそのものだ。** 1 回の呼び出しが、実際のターミナルペインに任意のキーストロークを入力する。その URL に到達できる人は誰でも、すべてのペイン(ソース、シークレット、環境変数、エージェントの出力)を読み、あなたのユーザーとして任意のコマンドを実行できる。サンドボックスもコマンド許可リストもない —— どちらもこのツールの目的そのものを消してしまうからだ。**この URL は root ログインと同じように扱うこと。**

デフォルトで有効な防御:

- **ループバックバインドのみ**(`127.0.0.1`) —— 決して `0.0.0.0` ではない
- **堅牢な玄関をちょうど 1 つだけ** —— `tailscale serve`(デフォルト)、または仕様に沿ったリバースプロキシ
- **`COLLIE_TRUSTED_USER`** —— 自分以外の tailnet アカウントをすべて拒否
- **`COLLIE_DEVICE_HEADER` + `COLLIE_DEVICE_ALLOWLIST`** —— デバイス単位の書き込み権限、それ以外は読み取り専用
- **`COLLIE_PUBLIC_HOSTS`** —— Host 検証により DNS リバインディングを遮断
- same-origin ゲートと厳格な CSP。ペインの出力は React のテキストノードとしてのみ描画される

> 🚫 **これに `tailscale funnel` を使ってはいけない。** funnel は公開インターネットに露出させてしまう。setnet を funnel で開くのが正しい場面は存在しない。

4 つのデプロイ形態(個人 tailnet / デバイスを認可するプロキシ / リバースプロキシ単独 / off-host アイデンティティプロキシ)の正確な設定は、誤ればそのまま事故になる領域なので、**翻訳せず英語の原文のまま維持している** —— [運用マニュアル → Security](OPERATIONS.md#%EF%B8%8F-security--read-before-you-run-it) と [Deployment variants](OPERATIONS.md#deployment-variants) を読むこと。

現状のまま提供され、いかなる保証もない。

## 来歴

setnet は [AltanS/collie](https://github.com/AltanS/collie) から分岐し、その上にクロスハーネスの層を重ねたものだ。Collie が先に証明したこと —— スマホからエージェントを追うことが実際に使いものになるということ、そしてそれを安全に公開する方法 —— はそのまま受け継いでいる。上流が磨き上げてきたインストール・セキュリティ・デプロイのドキュメント一式は、英語のまま[運用マニュアル](OPERATIONS.md)に保存してある。
